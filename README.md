# دفتر الكريدي

1. افتح المجلد في Android Studio وانتظر Gradle Sync، أو ارفعه على GitHub وسيبني APK تلقائياً (تبويب Actions).
2. تبويب «الكاشير»: امسح الباركود. منتج معروف = صوت قصير وإضافة تلقائية. منتج جديد = صوت مختلف ونافذة لحفظه (اسم + سعر + صورة).
3. الأصوات تعمل على مستوى صوت الوسائط (Media) في الجوال.
